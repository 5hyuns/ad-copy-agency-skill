# Headline specs by channel (United States)

v5 outputs headline lines only. Only the specs that affect the headline are kept here. Check any `[unverified]` value against the platform's official help page before use. Quotes are verbatim from the page named, checked 2026-10-02.

## SNS 피드 (Social feed)
- The headline is one short line. Image, brand name and logo appear with it.
- Meta (Facebook/Instagram) character recommendations: `[unverified]`. Meta's Ads Guide pages (facebook.com/business/ads-guide) returned HTTP 400 to a direct fetch on 2026-10-02, so no figure was confirmed from the page itself. A web search summary (not a page read) reported 125 characters primary text / 40 characters headline for carousel and collection ads, and 27 characters headline for Facebook Feed image ads. Confirm on https://www.facebook.com/business/ads-guide/update/image/facebook-feed/link-clicks and https://www.facebook.com/business/help/1114358518575630 before using any number. Meta's figures are recommendations for display, not hard input limits `[unverified]`.
- Sponsored, gifted or affiliate content: the material connection disclosure must be visible up front and not hidden behind "See more" or a link (`regulation.md` 2.1 and 2.2, 16 CFR 465.1(c)(4)).

## 검색광고 (Search ads)
- Google Responsive Search Ads, from Google Ads Help "About responsive search ads" (https://support.google.com/google-ads/answer/7684791?hl=en, checked 2026-10-02):
  - "The headline fields for responsive search ads support up to 30 characters. The description fields support up to 90 characters each, and the path fields support up to 15 each."
  - "Unlike expanded text ads, you can provide up to 15 headlines and 4 descriptions for a single responsive search ad."
  - "Enter your headlines. You’ll need to enter a minimum of 3 headlines, but you can enter up to 15. Enter your descriptions. You’ll need to enter a minimum of 2 descriptions, but you can enter up to 4."
  - "Keep in mind that headlines and descriptions may appear in any order. Try writing the first 3 headlines as if they’ll appear together in your ad."
  - So each headline must stand alone and still make sense in any combination; a claim and its condition cannot be split across two headlines.
- Microsoft Advertising Responsive Search Ads, from Microsoft Learn "Responsive Search Ads" (https://learn.microsoft.com/en-us/advertising/guides/responsive-search-ads?view=bingads-13, checked 2026-10-02):
  - "Responsive search ads in the Search network allow you to set between 3-15 unique ad headlines (a.k.a. "titles") and 2-4 ad descriptions within a single ad."
  - Character limits (30 per headline, 90 per description after dynamic text substitution): `[unverified]`. Seen only in a web search summary of the Bulk API record page https://learn.microsoft.com/en-us/advertising/bulk-service/responsive-search-ad?view=bingads-13; not read on the page.

## 상세·랜딩페이지 (Detail / landing page)
- The first-screen headline. No character limit.
- The FTC Deception Policy Statement says accurate body text "may not remedy a false headline because reasonable consumers may glance only at the headline" (`regulation.md` 1.2), so the headline must hold up without the rest of the page.

## 영상 스크립트 (Video script)
- The headline is used as the first on-screen caption or the first line of narration.
- TikTok Ads Help "Creative Best Practices" (https://ads.tiktok.com/help/article/creative-best-practices, checked 2026-10-02): "Prioritize your hook in the first 6 seconds to boost engagement and increase watch time. You can do so by creating suspense, surprise, or other emotions. Introduce your content proposition in the first 3 seconds for better recall and awareness. Use captions or text overlays to provide context to your ad. We recommend displaying 5-10 words per second when using text."
- Do not use figures such as "the first 6 seconds drive 90% of recall". `[unverified]`
- Disclosures in video must appear in the same means as the claim (visual and/or audible) (`regulation.md` 2.1, 16 CFR 255.0(f)).
