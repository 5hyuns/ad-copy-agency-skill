# 사실·규제 검수표

9단계 광고주 리뷰(`09-client-review.md`)에서 CD 후보에 적용합니다. **팀 프롬프트에는 옮겨 적지 않습니다.** 옮겨 적으면 제약이 곧 카피의 메시지가 됩니다.

## 0. 사실 검수 (모든 실행)

| 점검 | 질문 |
|---|---|
| 근거 | 제품에 대한 사실 주장(수치·일정·조건·가격·후기·인증·수상·성과)마다 `02-raw.md`의 F 항목이나 크리에이티브 브리프(`03-creative-brief.md`)의 믿을 이유·새로 찾은 것에 근거가 있는가? |
| 출처 등급 | 근거의 등급이 "의뢰인 제공"이 아니면 `[의뢰인 확인 필요]`가 붙어 있는가? 공개 자료끼리 어긋나는 사실(X 항목)을 한쪽만 골라 쓰지 않았는가? |
| 오인 | 헤드라인만 읽었을 때 조건·제한을 잘못 이해할 여지가 있는가? 있다면 서브·본문에서 바로잡아야 할 것으로 적는다. |
| 가상 표시 | 가상의 장면·인물이 실제 후기나 사례처럼 읽히지 않는가? |
| 사람의 말 | V(사람의 말)의 인용을 이 제품의 이용자 후기처럼 쓰지 않았는가? 개인을 알아볼 수 있는 정보가 없는가? |

아래 1~3절이 규제 점검입니다.

> ⚠️ 조항 번호와 벌칙은 법률 정보 사이트(CaseNote) 사본에서 가져왔습니다. law.go.kr 원문과 대조하기 전에는 **참고용**입니다. 이 점검은 위험 표현을 **표시**하는 용도이고, 법적 판단이 아닙니다.
> 출처: `research/copywriters/00-general-agency-process.md` 6장

## 1. 공통: 표시·광고의 공정화에 관한 법률 (모든 실행에서 점검)

| 유형 | 점검 질문 | 위험 신호 |
|---|---|---|
| 거짓·과장 | 사실과 다르거나 지나치게 부풀렸는가? | "최고", "1위", "유일", "100%", "완벽" 등 근거 없는 최상급 |
| 기만 | 불리한 사실을 숨기거나 축소했는가? | 조건·제한을 작게 쓰거나 빼기, "무료"인데 조건부 |
| 부당 비교 | 비교 대상·기준·근거를 밝혔는가? | "타사보다 2배", "업계 최저가"에 출처 없음 |
| 비방 | 객관 근거 없이 경쟁사를 깎아내렸는가? | 경쟁사를 특정할 수 있는 부정 표현 |
| 실증 | 사실 주장마다 입증 자료가 있는가? (제5조) | 입력 자료에 없는 수치·효과 주장 → 이 스킬에선 `[확인 필요]`로 남아 있어야 함 |

## 2. 공통: 추천·보증 등에 관한 표시·광고 심사지침 (후기·협찬·제휴가 있을 때)

- 2024-12-01 시행 개정 기준입니다.
- 경제적 이해관계 표시("광고", "협찬" 등)는 게시물 **제목 또는 첫 부분**에 명확하게 넣습니다.
- 판매 수수료나 후기 작성 후 환급 같은 미래·조건부 대가도 표시 대상입니다.
- "소정의 수수료를 받을 수 있음" 같은 불확정 표현은 쓸 수 없습니다.
- 후기·추천 문구는 입력된 원문에서만 가져옵니다. 지어낸 후기는 금지입니다.
- 동영상·라이브의 반복 표시 방식은 `[미확인]`입니다. 안내서 원문을 확인하세요.

## 3. 업종별 (업종이 주어졌을 때)

### 식품 (식품 등의 표시·광고에 관한 법률 제8조 제1항)

| 호 | 금지 | 위험 표현 예 |
|---|---|---|
| 1 | 질병 예방·치료 효능 인식 | "면역력 강화", "혈당 개선", "OO병 예방" |
| 2 | 의약품으로 인식 | "처방", "치료제처럼" |
| 3 | 건강기능식품이 아닌데 건강기능식품으로 인식 | 일반 식품에 기능성 표현 |
| 4~7 | 거짓·과장, 기만, 비방, 부당 비교 | 1절과 같음 |
| 8~10 | 사행심·음란, 오인·혼동, 심의 위반 | 건강기능식품은 심의 결과와 동일하게 |

- 벌칙: 1~3호는 10년 이하 징역 또는 1억 원 이하 벌금, 4~10호는 5년 이하 또는 5천만 원 이하 벌금입니다. `[원문 대조 필요]`
- "무설탕", "제로" 같은 영양 강조 표시는 별도 표시 기준이 있습니다. `[미확인]`, 식약처 기준 확인이 필요합니다.
