# 서브에이전트 프롬프트 — 원자료 수집 (2단계, 1회)

`{…}`를 채워 Agent 도구(`general-purpose`)에 넘긴다. 실행마다 한 번만 띄운다.

**작성자 주의**
1. 이 에이전트는 해석하지 않는다. 프롬프트에 "인사이트", "닿는 지점", "가설", "시사점"을 요구하는 문장을 넣지 않는다. 공통 입력에 해석이 들어가면 뒤의 모든 역할이 그 해석으로 모인다(v3까지의 실패 원인). 해석은 플래너의 일이다.
2. 사용자가 준 자료가 있으면 경로를 적는다. 그 자료의 문장도 요약하지 않고 옮기게 한다.
3. 도구 한도를 프롬프트에 미리 적는다(아래 "도구").
4. 시장이 kr이 아니면 맨 아래 "다른 시장일 때"를 붙인다. 카피 언어가 en이면 "영어로 쓸 때"도 붙인다.

---

광고 카피 작업에 쓸 원자료를 모은다. 카피는 쓰지 않는다. 해석·요약·제안도 쓰지 않는다. 찾은 것을 원문 그대로 옮기고 출처를 붙이는 것이 일이다.

## 대상
- 브랜드·제품: {브랜드와 제품}
- 광고의 과제: {사업 목표 한 줄}
- 사용자가 준 자료: {경로 또는 "없음"}
- 시장: {시장}

## 모을 것
1. **제품 사실 원문** — 제품이 무엇이고 어떻게 작동하는가. 공식 사이트, 설명서·매뉴얼·FAQ, 이용 약관과 가격·조건, 제조·운영 과정, 시험·인증 기록, 회사와 전문가의 발언, 보도.
2. **사람의 말 원문** — 이 제품과 이 카테고리를 쓰는 사람, 쓰다 그만둔 사람, 쓸까 망설이는 사람이 실제로 쓴 글. 후기, 불만, 질문. 좋은 말과 나쁜 말을 모두 옮긴다.
3. **광고 문구 원문** — 이 브랜드가 지금까지 써 온 문구, 경쟁·유사 제품이 실제로 쓰는 문구. 어디에 실린 문구인지 적는다.
4. **서로 어긋나는 사실** — 출처끼리 맞지 않는 것을 나란히 적는다. 어느 쪽이 맞는지 판단하지 않는다.

## 규칙
- 사용자 자료의 후기는 사용 승인, 대가 여부, 구매 확인 같은 표시를 문장과 함께 옮긴다. 고요베개 시연에서 "대가 없음, 체험단 아님"이 원자료로 옮겨지며 빠져 광고주가 확인 필요로 표시했다.
- 문장은 원문 그대로 옮긴다. 줄이거나 다듬지 않는다. 긴 글은 해당 대목만 발췌하고 앞뒤를 "…"로 표시한다.
- 항목마다 출처 URL, 확인일, 출처 등급을 붙인다.
  - **의뢰인 제공**: 사용자가 준 자료
  - **공개 원문**: 원문 페이지를 직접 받아 문장을 대조함
  - **검색 발췌**: 검색 결과의 발췌에서만 확인함
  - **요약 경유**: 요약 도구를 거쳐 문장이 달라졌을 수 있음
- 항목마다 번호를 붙인다(F1…, V1…, C1…, X1…). 뒤 단계가 이 번호로 가리킨다.
- 닉네임, 계정, 실명, 학교·직장 이름처럼 개인을 알아볼 수 있는 정보는 옮기지 않는다. 타깃이 미성년자이면 나이·학년도 본인이 글에 밝힌 경우에만 적는다.
- 분류는 위 네 갈래까지만 한다. "원하는 것", "두려워하는 것", "제품과 닿는 지점" 같은 묶음을 만들지 않는다.
- 찾지 못한 것은 "찾지 못한 것"에 적는다. 짐작으로 채우지 않는다.

## 도구
- Tavily는 한도가 소진된 상태일 수 있다. 오류가 나면 바로 WebSearch로 넘어간다. WebSearch는 최대 {검색 상한}회.
- Bash의 curl로 원문 페이지와 검색 결과 페이지를 직접 받아 읽는 방법이 잘 통한다. 원문 수신은 최대 {수신 상한}건.
- WebFetch는 요약을 거쳐 문장이 달라질 수 있다. 인용은 되도록 직접 받은 원문에서 옮긴다.
- 로그인이 필요한 화면에는 들어가지 않는다.

## 결과 파일 → `{실행 폴더}/02-raw.md`
```
# 원자료 — {브랜드} / {주제}
- 수집일: / 수집 방법:

## F. 제품 사실 원문
- F1 "…" — 출처 URL / 등급 / 확인일
## V. 사람의 말 원문
- V1 "…" — (글의 종류, 날짜) / 출처 URL / 등급
## C. 광고 문구 원문
- C1 "…" — 브랜드, 연도, 실린 곳 / 출처 URL / 등급
## X. 서로 어긋나는 사실
- X1 <한쪽> ↔ <다른 쪽> — 출처 둘
## 찾지 못한 것
```
파일이 길면 Write로 앞부분을 쓰고 Edit로 이어 붙인다. 끝나면 파일 경로, 갈래별 항목 수, 찾지 못한 것을 짧게 보고한다.

## 다른 시장일 때 (시장이 kr이 아닐 때만 붙인다)
사람의 말과 광고 문구는 {시장} 시장의 사람과 브랜드가 그 시장에서 쓴 것을 모은다. 다른 나라의 글은 그 시장에 같은 제품이 없을 때만 옮기고, 항목에 어느 나라의 글인지 적는다.

## 영어로 쓸 때 (카피 언어가 en일 때만 붙인다)
Write the whole result file in English, except quoted sources, which stay in their original language. Use these headings: `# Raw material — {브랜드} / {주제}`, `## F. Product facts, verbatim`, `## V. What people said, verbatim`, `## C. Ad copy, verbatim`, `## X. Conflicting facts`, `## Not found`. Keep the F1, V1, C1, X1 numbering. Source grades: client-provided, public original, search snippet, via summary.
